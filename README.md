# Htuu Care – Community Health Intelligence

AI-enabled community health information and public-health intelligence platform.

## Goal
Connect Htuu Care, the 7887 Healthcare Call Center, and scalable cloud infrastructure to identify aggregated health-information demand and support targeted public-health awareness.

## Safety principle
AI supports information analysis and prioritization. It does not diagnose individuals or make autonomous clinical or public-health decisions.

## Architecture
Community → Htuu Care → 7887 human support → Cloudflare → AI Community Health Intelligence → aggregated trends → public-health dashboard/reports → human review → awareness and service response.

## Initial pilot
Hlaing Tharyar Township, Yangon, Myanmar.

## Technology
- Node.js
- Telegram Bot API
- GitHub
- Cloudflare Workers
- Cloudflare D1 / Queues / R2 as appropriate
- AI-based topic classification and trend analysis

## Data protection
Use data minimization, role-based access, secure secrets, and aggregated/non-identifying outputs for public-health intelligence.

## Status
Early-stage MVP foundation.
